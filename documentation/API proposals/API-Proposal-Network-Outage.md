# API Proposal
| **Field** | Description | 
| ---- | ----- |
| API family name | Network Outage API |
| API family owner | EE |
| API summary | The Network Outage API provides a standard way for authorised devices, apps and support channels to check whether a customer is affected by a known mobile network outage, service degradation or planned maintenance event It helps explain poor or lost connectivity using operator network data, so customers can be given clearer information instead of being pushed through unnecessary troubleshooting or support journeys. |
| Technical viability | The Network Outage API is highly feasible to implement as mobile network operators already maintain network monitoring, incident management, and service assurance platforms that continuously track the operational status of network infrastructure and services. <br><br> Use cases:<br> • Check if a device/location is affected by a known outage<br> • Show clear customer messaging during network issues<br> • Support planned maintenance notifications<br> • Update customers when an issue is resolved<br> • Keep outage information consistent across device, app, web and care channels<br> • Help OEMs and digital channels respond better when a device detects poor service |
| Commercial viability | The Network Outage API offers strong commercial potential by transforming operational network intelligence into a consumable service for enterprises, digital platforms, and public sector organizations. Many businesses today depend on mobile connectivity but have limited visibility into local network disruptions that affect customer experiences, transactions, and service delivery. <br><br> Target Customers:<br> • OS providers<br> • Banks and financial institutions<br> • Payment service providers<br> • Digital service providers<br> • Insurance companies<br> • Logistics and fleet operators<br> • Emergency services<br> • Enterprise IT and operations teams |
